FAQ & troubleshooting

Start with the symptom table. Most failures are a missing image URL, an expired token, dry run still on, or a guard rail doing its job — and the Activity log usually names the one.

Every failure is recorded twice: on the item (queue row or message) and in the Activity log with the API response. Read those two places before changing settings at random.

Symptom → fix

SymptomWhat to check
Window is blank or the app fails to draw The app should already use software rendering. If you set MARKETPILOT_GPU=1, remove it and restart. On a remote desktop or VM, keep software rendering.
Banner says “Read-only” The 72-hour trial or the paid term has ended, or the system clock moved backwards. Open License & plans to see the reason, then activate a key or fix the date and time. Data is untouched.
“Nothing due” on a tick No enabled cadence at this weekday/time, no approved post whose schedule has passed, scheduler switch off, or an active campaign with nothing prepared. --status shows the counts.
Post is SIMULATED Dry run is on. That is expected; nothing was sent. Switch to Live only when you mean it.
Post is FAILED with 401 or 403 The token expired or lacks a scope. Re-issue it, paste it in Settings, press Test connection, then re-queue the post.
Post fails with 429 or a rate-limit message The platform's tier is too low for the cadence. The scheduler retries after 15 and 30 minutes; reduce the cadence or raise the tier if it persists.
Instagram fails about an image Set a per-post public image URL, or set the image base URL and upload the generated PNG under exactly the same file name. The URL must be publicly reachable without a login.
WhatsApp fails outside the 24-hour window Configure an approved marketing template and its language in Settings. Free-form text only works inside an open conversation.
Manual outbox is empty Dry run is on. Bundles are only written in live mode, even though nothing is uploaded.
Reel is missing from the bundle FFmpeg path is wrong, Check has not passed, or Render vertical reels is off. Re-render or re-queue after fixing it.
Cadence produces nothing Check enabled, selected weekdays, the brand timezone, whether it already ran today, and the Activity log. Press Run now to test generation without waiting.
Nothing sends to leads Campaign not ACTIVE, lawful-basis box not ticked, all leads suppressed or uncontactable, outside the sending window, or the campaign cap is already reached. The log names the reason.
Newsletter has no recipients Newsletters only go to leads marked Subscribed. One-to-one outreach does not require that flag.
AI test fails Provider and key do not match, the model name is not available to that key, the free quota is exhausted, or a proxy blocks the request. The error is shown in plain language.
Two brands but one set of accounts Credentials are per installation, not per brand. Use separate Windows users or installs for unrelated customers.
SmartScreen blocks the installer The 1.2.0 build is unsigned. Verify the SHA-256, then choose More info → Run anyway. Sign future builds before public distribution.
Gradle task hangs after closing the app A stale Gradle or Java daemon can hold the build lock. End the stray java process and retry with --no-daemon. This affects building from source, not the installed app.

Diagnostics that help

  1. Read the Activity log

    Filter by WARN and ERROR. The message includes the connector and the API's own error text.

  2. Run Masar.exe --status

    Shows counts, dry run and scheduler state without changing anything.

  3. Test the connector

    Settings → Channels → Test connection. It performs a safe read and never publishes.

  4. Check the clock and timezone

    Cadence times and sending windows use the brand timezone, not the Windows clock's zone.

  5. Inspect the data folder

    %APPDATA%\MarketPilot\data holds workspace.json and settings.properties. Close the app before copying or editing them.

Never delete workspace.json to fix a bug. It contains every brand, post, lead, campaign and log entry. Back up the folder first. If you must reset, rename the file rather than removing it, so it can be recovered.

Known limitations

  • Instagram needs a public image URL. The app does not upload images to a CDN. Host the media folder yourself, or paste a per-post URL.
  • WhatsApp marketing needs a pre-approved template with exactly one body placeholder. Only that parameter is filled.
  • Google Business Profile access must be granted by Google before the connector works. It is not a self-serve API.
  • TikTok has no self-serve posting API for most accounts. Use the Manual channel and upload from your phone.
  • LinkedIn and Google tokens expire. Refresh them in Settings when the log says so. Person tokens last about 60 days.
  • Facebook, LinkedIn and X publish text and links only. The branded PNG is saved locally but not uploaded by those connectors.
  • The in-app scheduler only runs while the window is open. Use Task Scheduler for 24/7 operation.
  • No drip sequences, follow-up automation, scraping or purchased lists. One contact per campaign. These are deliberate product choices, not missing features.
  • The AI writer cannot see your calendar, inventory or prices. Keep offers current in the brand profile so the copy stays truthful.
  • Credentials are per installation, not per brand. Separate customers need separate Windows users or installs.
  • No auto-update. Replace the build manually; the data folder is preserved.
  • The 1.2.0 build is unsigned. Windows SmartScreen will warn on first run.

Trial, licence and activation

What happens after the 72-hour trial?

The app switches to read-only. Everything on disk stays visible and unchanged; creating, approving, publishing, importing and outreach pause, and the scheduler stops sending. Activate a key in License & plans to continue.

Where do I buy a licence?

In the app, open License & plans and press Buy on WhatsApp under a plan, or use the buttons on the pricing page. Plans are 1 month for $15, 3 months for $39 and 1 year for $129. You pay in the chat and receive a key there.

Does activation need internet?

No. The key is signed by the seller and checked on your PC with a public key built into the app. Nothing is sent anywhere, and no account is created.

Can I reuse a key or move it to another PC?

A key activates once per installation. If you reinstall Windows or change PC, message the seller with the key id shown under License & plans and a replacement is issued. The remaining days live in your data folder, so a normal reinstall keeps them.

Why does it say the clock moved backwards?

The app remembers the last time it ran. If the system clock jumps back more than two hours, the licence pauses to stop the trial from being extended. Set Windows time to automatic and reopen the app.

Can I run the scheduler without the window open?

Yes, through Task Scheduler and Masar-cli.cmd --once. It needs an active licence: in read-only mode the command exits with code 2 and sends nothing.

Frequently asked questions

Is there a subscription or a Masar account?

There is no account and no auto-renewing card charge. A fresh install gets a 72-hour trial; after that you buy a prepaid term on WhatsApp and activate the key offline. Nothing is stored on a server, and the app has no sign-up and no telemetry. You pay your own AI provider and any platform fees; channel APIs use your own credentials.

Can I use one install for several customers?

For brands that share the same accounts, yes: add a brand per business. Credentials are per installation, so two unrelated customers should not share one Windows user. Install a second copy under another Windows user, or use a separate PC/VM. Back up each data folder separately.

Does it work offline?

You can open the app, edit the brand profile, review the queue and read logs offline. AI generation and every publish or send need internet access. Manual bundles are written locally but still require live mode.

Can it post to Instagram Stories, TikTok or Reels directly?

Not directly. TikTok has no self-serve posting API for most accounts, and Stories/Reels are covered by the Manual channel. You get a caption, image, optional 8-second MP4 reel and metadata in the outbox, ready to upload from the phone.

Can I reply to comments or DMs automatically?

No. Masar publishes content, sends approved outreach and records activity. It does not monitor inboxes, scrape comments or automate replies.

Is the AI writer required?

No. Without a key the app uses deterministic templates that fill the brand facts into proven structures. With a key, the copy is tailored per brand, pillar and lead. You can switch providers at any time.

What happens to my content when I use AI?

The brand profile, brief and channel limits are sent to the provider you configured. Artwork is rendered locally. Nothing is sent to Masar itself. Review your provider's data policy before pasting confidential offers or customer details into a brief.

Can I use a different language?

The interface is English. Write the brand voice and brief in the language you want, and review the generated copy. Platform limits are applied by character count, so check the preview before approving.

Does it run on macOS or Linux?

The published build is Windows only. The source is Kotlin/Compose Desktop, which is cross-platform, but the packaged 1.2.0 artifact and its instructions are Windows 10/11 x64.

How do I update or uninstall?

Install the new MSI over the old version, or replace the portable folder. There is no auto-update. To uninstall the MSI, use Settings → Apps → Installed apps → Masar → Uninstall; for the portable build, delete the folder. The uninstaller does not remove %APPDATA%\MarketPilot — delete that separately if you want a clean slate.

Can I move the workspace to another PC?

Yes. Close the app, copy data and media to the same location on the new PC, install Masar, and launch. Re-enter channel credentials instead of copying settings.properties if you are unsure who can read the old machine. See data and backup.

Why is my post held instead of published?

One of the guard rails fired: outside the sending window, daily cap reached for that channel, or the minimum gap has not passed. Simulated posts count too. The Activity log states the exact reason, and the post stays approved for a later tick.

Before you ask for help

Collect these details; they make almost every issue reproducible without access to your machine:

  • Masar version (1.2.0) and whether you use the MSI or portable build.
  • Windows version and whether this is a normal desktop, VM or remote session.
  • The exact queue status or message status, plus the Activity log lines around the failure.
  • The channel, the step (test, publish, send) and the API error text.
  • What changed since it last worked: token, key, cadence, timezone, network.

Redact before sharing. Remove tokens, API keys, email addresses and phone numbers from screenshots and log excerpts. Nobody needs your Page token to diagnose a scheduling problem.
