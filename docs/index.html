MarketPilot is a Windows desktop app for running a small business's marketing week: writing posts, rendering artwork, scheduling a queue, publishing through official APIs, and preparing lawful outreach. All state lives in local files.

New here? Read the setup guide in order once. It takes about 45 minutes to a first safe, simulated post. After that, the daily routine at the end of the guide is enough.

Start with the guide

  1. Install and open

    Use the MSI or the portable ZIP. First launch creates %APPDATA%\MarketPilot with one brand and safe defaults.

  2. Fill the brand profile

    Name, one-liner, audience, services, city, voice and banned words. The writer treats these as facts.

  3. Connect one channel

    Manual needs nothing. Add a social channel or SMTP when you have credentials.

  4. Draft, queue, tick

    Watch a post become SIMULATED. Only then consider live mode.

Conventions used here

ConventionMeaning
SIMULATEDDry run was on. The action was logged but nothing left the machine.
%APPDATA%\MarketPilotThe per-user data folder, usually C:\Users\<you>\AppData\Roaming\MarketPilot.
Settings → …A section inside the app's Settings screen.
MonospaceA file path, credential value, command or literal state.
“Tick”One scheduler pass: materialise cadences, publish due posts, send approved messages.

Quick reference

Headless in one line

From the installed app:

MarketPilot.exe --once

Add --dry-run, --force or --status. See CLI flags.

Where everything lives

data\workspace.json — brands, posts, leads, campaigns, logs.
data\settings.properties — keys and tokens, plain text.
media\ — images and reels.
outbox\ — manual bundles.

Version note. This manual documents MarketPilot 1.1.0. The app does not auto-update. When you replace the build, keep %APPDATA%\MarketPilot to retain brands, queue and history.
