Channels & credentials

Every connector uses an official API. This chapter lists the exact fields the Settings screen expects, what each platform requires before the fields will work, and how images travel — or do not.

Open Settings → Channels. Each card shows whether it is configured, and each card has its own Save and Test connection. Fill only the channels you actually use; the rest can stay empty forever.

Credentials are per installation, not per brand. They live in %APPDATA%\MarketPilot\data\settings.properties as plain text. Two brands on one install share the same Page, token and mailbox. For unrelated customers, use separate Windows users or installs.

How artwork travels

Every post gets a branded PNG rendered locally. Whether a platform receives it depends on the API:

  • Instagram requires a public image URL. Either paste one on the post, or set an image base URL and upload the generated PNG to the matching folder on a static host.
  • Google Business Profile accepts an optional public photo URL. Set a per-post public image URL if you want the photo attached.
  • Manual includes image.png (and an optional reel) in the outbox bundle.
  • Facebook, LinkedIn and X connectors publish text and links only. The PNG stays in the local media folder for you to attach manually if you want an image.

There is no CDN inside MarketPilot. For Instagram and Google photos, host the media folder somewhere public or maintain a small upload script. The app deliberately does not upload your images to a third-party service.

Facebook Page

Prerequisite: a Facebook Page and a Meta app of the Business type with the Pages API. Connect the Page to the app, then generate a Page access token.

Required scopes: pages_manage_posts, pages_read_engagement, pages_show_list.

FieldKeyWhat to paste
Page IDpage_idThe numeric ID of the Page (not the username).
Page access tokentokenA Page token, not a user token.

Test connection resolves the Page name. Publishing sends the post text plus an optional link to the Page feed. A user token usually fails with a permission error even when the Page is correct.

Instagram

Prerequisite: an Instagram Business account linked to a Facebook Page. Publishing goes through the Instagram Graph API using that Page's app and token.

Required scopes: the Page scopes above plus Instagram content publishing permissions granted through the linked Page.

FieldKeyWhat to paste
Instagram Business account IDuser_idThe business account ID, not the @handle.
Page access tokentokenThe same Page token used for Facebook.
Public image base URLimage_base_urlOptional, but the usual way to publish images. Example: https://example.com/marketpilot/media.

If the post has a public image URL, that URL wins. Otherwise MarketPilot appends the generated PNG's file name to the base URL. The exact file name must exist under that URL. If neither is available, the post fails with a clear message instead of publishing the caption alone.

Instagram publishing is a two-step container flow: create the media container, then publish it. The app waits and retries briefly while Instagram finishes processing the image.

LinkedIn

Prerequisite: a LinkedIn app with w_member_social for personal posting, or access to the Community Management API for organisation pages.

FieldKeyWhat to paste
Author URNauthorurn:li:person:… or urn:li:organization:…
Access tokentokenOAuth 2.0 bearer token with post permission.
API versionversionOptional. Defaults to 202507; use the version enabled for your app.

Posts are public text posts on the main feed. Person tokens last about 60 days; organisation tokens differ. When the log shows a 401 or 403, re-issue the token and paste the new value.

X

Prerequisite: an X developer app with OAuth 2.0 user-context write access. The app posts one text update per action.

FieldKeyWhat to paste
OAuth 2.0 user tokentokenA user-context token with tweet.write and users.read.

Free and lower tiers are rate-limited. The scheduler retries rate limits with backoff rather than hammering the endpoint; a persistent 429 needs a smaller cadence or a higher tier.

Google Business Profile

Prerequisite: the API is not self-serve. Request access through Google's Business Profile API form, wait for approval, then create OAuth credentials with the Business Profile scope.

FieldKeyWhat to paste
Account IDaccount_idThe Business Profile account ID, or leave blank to use me.
Location IDlocation_idThe location to post to. Required.
OAuth client IDclient_idFrom the Google Cloud OAuth client.
OAuth client secretclient_secretFrom the same client.
Refresh tokenrefresh_tokenObtained with offline access and the Business Profile scope.

The app exchanges the refresh token for a short-lived access token and caches it until it expires. Local posts are short updates with an optional call-to-action link; use the Local pillar for neighbourhood-specific copy. A public image URL is required if you want a photo attached.

Email and SMTP

Prerequisite: any SMTP provider — Google Workspace, Microsoft 365, Brevo, Mailgun SMTP, or your web host. Use an app password, not your normal login.

FieldKeyWhat to paste
SMTP hosthostFor example smtp.gmail.com.
Portport587 for STARTTLS or 465 for SSL.
SMTP usernameuserUsually the full email address.
SMTP passwordpasswordAn app password, stored locally.
From addressfromThe visible sender address. Must be allowed by the provider.
From namefrom_nameThe visible sender name.
Unsubscribe mailboxunsubscribe_emailWhere “stop” replies go. Every email also gets a List-Unsubscribe header.

Messages are plain text, sent to the From address with recipients in BCC, and include the brand's postal address and an unsubscribe line. Replies to the unsubscribe mailbox must be honoured manually: press Unsubscribe on the lead so future sends are blocked.

Deliverability tip. Use a subdomain or a warmed-up mailbox for outreach, keep volumes low, and send newsletters only to contacts marked Subscribed. The app cannot fix a domain with no SPF, DKIM or DMARC.

WhatsApp Cloud API

Prerequisite: a Meta app with WhatsApp Business, a verified sender, and an approved template for marketing messages outside the 24-hour service window.

FieldKeyWhat to paste
Phone number IDphone_number_idThe Cloud API phone number ID, not the phone number.
Cloud API tokentokenA system user or temporary token with messaging permission.
Approved template nametemplateFor example marketing_update. Leave blank only for open 24-hour conversations.
Template languagetemplate_langFor example en_US. Defaults to en_US.

The message text is sent as the template's body parameter {{1}}. The template itself must have exactly one body placeholder. Without a template, only free-form replies inside an open 24-hour conversation work — that is a Meta rule, not an app setting.

Manual / TikTok / Reels

No credentials, always available. Publishing writes a bundle to %APPDATA%\MarketPilot\outbox\<brand>\<post>\:

FileContents
caption.txtPost text and hashtags, ready to paste.
image.pngThe branded card rendered locally.
post.jsonStructured post metadata for your own tooling.
README.txtA short reminder of what to upload where.
reel.mp4Optional 8-second 1080×1920 clip when FFmpeg is configured.

Dry run does not write bundles. Switch dry run off for this action, run a tick, then upload from your phone. For reels, set the FFmpeg path in Settings → Short-form video, press Check, and enable Render vertical reels.

Testing and rotation

  • Test connection performs a safe read — it never publishes. Use it after every credential change.
  • Expiry usually shows as a 401 or 403 in the Activity log. The queue row stops retrying; paste a new token and re-queue the post.
  • Rotation — replace the value in Settings and save. No restart is needed.
  • Storage — tokens are plain text in settings.properties. Do not sync that file to shared cloud storage. The Windows account is the security boundary.

Never paste credentials into a support ticket or screenshot. Tokens grant posting rights to your Pages and accounts. Revoke a leaked token in the platform's developer console first, then replace it here.
