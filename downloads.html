Installation

Two ways in.

MSI installer

  1. Run the MSI

    Double-click MarketPilot-1.0.0.msi. Approve the SmartScreen prompt if it appears.

  2. Follow the wizard

    The default install is per user and needs no administrator rights. You can choose the folder.

  3. Launch from the Start menu

    Open MarketPilot. The first launch creates %APPDATA%\MarketPilot with one brand and safe defaults.

Portable ZIP

  1. Extract the archive

    Right-click the ZIP → Extract All. Keep the whole MarketPilot folder together; the runtime lives inside it.

  2. Run the EXE

    Open MarketPilot\MarketPilot.exe. Do not move the EXE out of the folder.

  3. Optional: pin it

    Create a desktop shortcut to the EXE. To remove the app later, delete the folder — app data stays in %APPDATA% until you remove it.

First launch is safe. Dry run is ON, the approval lock is ON, and the scheduler only acts on approved items. Nothing is posted, emailed or written to the outbox until you switch dry run off.

After installing

The first fifteen minutes.

  1. Fill the brand profile

    Name, one-liner, audience, services, city, tone and banned words. The copywriter treats these as facts and will not invent what is missing.

  2. Add an AI key — or skip it

    Gemini, OpenAI, OpenCode Zen or Go. Press Test key & model. Without a key the app falls back to deterministic templates.

  3. Connect one channel

    Manual is always available. Add Facebook, Instagram, LinkedIn, X, Google Business, SMTP or WhatsApp when you have the credentials.

  4. Generate two or three drafts

    Read them. Adjust the brief or the brand tone until the voice sounds like you.

  5. Queue one post and run a tick

    Dry run marks it SIMULATED. When you trust the output, switch to live for one low-risk channel.
